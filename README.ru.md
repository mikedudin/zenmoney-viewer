# ZenMoney Expense Viewer — Дашборд и аналитика личных финансов

![Версия 1.0](https://img.shields.io/badge/version-1.0-blue.svg)

[English](README.md) | **Русский**

🔗 **Демо пример:** [https://mikhaildudin.ru/ztest/](https://mikhaildudin.ru/ztest/)

> [!CAUTION]
> **Перед развёртыванием обязательно настройте аутентификацию**
>
> Это приложение отображает ваши **личные финансовые данные** (история трат, суммы транзакций, категории, контрагенты). Репозиторий **не содержит никаких механизмов аутентификации** — демо-страница намеренно открыта и использует только анонимизированные тестовые данные.
>
> **Перед развёртыванием с реальными данными вы обязаны настроить защиту доступа на сервере.** Без этого любой человек, знающий URL, сможет:
> - 👁️ **Просмотреть** вашу полную финансовую историю
> - 💾 **Перезаписать или безвозвратно уничтожить данные** — эндпоинт импорта CSV (`api/import.php` / маршрут импорта в Node.js) не защищён и заменит `data.json` любым загруженным файлом, что приведёт к **необратимой потере данных**
>
> Рекомендуемые варианты в зависимости от хостинга:
> - **Apache / cPanel**: HTTP Basic Auth через `.htaccess` + `.htpasswd` (см. раздел [Безопасность](#-безопасность) ниже)
> - **Node.js / Nginx / Caddy**: reverse-proxy с парольной защитой или middleware сессионной авторизации
> - **Статический хостинг** (GitHub Pages, S3, Netlify и т.п.): защищайте на уровне CDN/платформы (Netlify Identity, Cloudflare Access) или вовсе не размещайте реальные данные там
>
> ⚠️ Без аутентификации все ваши финансовые записи будут открыты в публичном интернете, а хранимые данные останутся уязвимы к случайной или намеренной перезаписи.

Современный, быстрый и автономный веб-дашборд для наглядного анализа личных расходов из приложения **Дзен-мани (ZenMoney)** ([Android](https://play.google.com/store/apps/details?id=ru.zenmoney.androidsub) / [iOS](https://apps.apple.com/ru/app/дзен-мани-учет-расходов/id905934786)).

Работает полностью на чистом JavaScript (без фреймворков и тяжелых библиотек), мгновенно открывается в браузере и поддерживает запуск как на **PHP**-хостинге, так и на **Node.js**.

---

## ✨ Возможности

- 📊 **Общий обзор**: общая сумма расходов, динамика по месяцам, топ категорий и крупные траты за всё время.
- 📅 **Анализ по месяцам**: детальный срез за любой месяц, средний чек в день, топ категорий месяца и список всех операций.
- 🏷️ **Анализ по категориям**: динамика трат по выбранной категории по месяцам, список получателей и детальная история.
- 🌐 **Двуязычный интерфейс**: поддержка русского и английского языков с переключателем в правом верхнем углу (используется Google Noto Color Emoji). Язык элементов управления, аналитики и дат переключается на лету, а язык самих записей расходов (категории, получатели, комментарии) отображается так, как вы ввели их в приложении Дзен-мани.
- 🔄 **Импорт CSV с дедупликацией**: загрузка выгрузки из Дзен-мани прямо через интерфейс (кнопка «Импорт CSV» в сайдбаре). Повторяющиеся транзакции автоматически отфильтровываются.
- ⚡ **Два варианта бэкенда**:
  - **PHP / Apache** (`index.php`, `api/data.php`, `api/import.php`) — идеально для любого виртуального хостинга.
  - **Node.js / Express** (`server.js`) — для локального запуска или VPS.
- 🔒 **Защита данных**: конфиденциальный файл `data.json` защищён от прямого скачивания через `.htaccess`.

## 🚀 Быстрый запуск

### Вариант 1: Запуск на Node.js

Требуется Node.js 16+.

```bash
# 1. Установите зависимости (Express)
npm install

# 2. Запустите сервер
npm start
```
Откройте в браузере: **`http://localhost:3000`**

---

### Вариант 2: Запуск через встроенный сервер PHP (локально)

Если у вас установлен PHP 7.0+:

```bash
php -S localhost:8000
```
Откройте в браузере: **`http://localhost:8000`**

---

### Вариант 3: Развёртывание на хостинге (Apache / cPanel / LAMP)

Требуется **PHP 7.0+**.

1. Загрузите файлы в нужную папку на веб-сервере (например, `public_html/zmoney/`).
2. При необходимости защиты доступа паролем настройте `.htaccess` и `.htpasswd` непосредственно на сервере:
   ```apache
   AuthType Basic
   AuthName "ZenMoney Viewer — Доступ закрыт"
   AuthUserFile /полный/путь/к/папке/.htpasswd
   Require valid-user
   ```
3. Убедитесь, что веб-сервер имеет права на запись в файл `data.json` (для работы импорта новых расходов):
   ```bash
   chmod 664 data.json
   ```

## 📥 Как экспортировать данные из Дзен-мани (ZenMoney)

### 📲 Экспорт из приложения Дзен-мани:
1. Откройте приложение Дзен-мани ([Android](https://play.google.com/store/apps/details?id=ru.zenmoney.androidsub) / [iOS](https://apps.apple.com/ru/app/дзен-мани-учет-расходов/id905934786) или в веб-версии).
2. Перейдите в **Настройка аккаунта → Экспорт операций в CSV** (*Account Settings > Export transactions to CSV*).
3. Выберите период: как правило, для полной картины расходов выбирают **«Вся история»** (*Full history*).
4. Нажмите **Экспортировать** и сохраните полученный CSV-файл на устройство.

> [!TIP]
> **Язык данных:** переключатель в дашборде переводит интерфейс, графики, даты и системные блоки. Сами названия категорий, контрагентов и комментарии выводятся на том языке, на котором вы их вводили в приложении Дзен-мани.

### 💻 Загрузка данных в дашборд:

#### Вариант 1: Прямо через веб-интерфейс (рекомендуется)
1. В дашборде нажмите кнопку **«Импорт CSV»** в левой панели (сайдбаре).
2. Выберите экспортированный `.csv` файл.
3. Приложение автоматически обработает операции: отфильтрует доходы и внутренние переводы между своими счетами, исключит дубликаты и сразу обновит графики и аналитику.

#### Вариант 2: Через консольный Python-скрипт (для статического хостинга)
Скрипт `convert.py` (требует **Python 3.6+**) работает как офлайн-обработчик данных. Он незаменим, если вы хотите разместить дашборд на полностью статичном хостинге (например, GitHub Pages или AWS S3), где нет бэкенда на PHP или Node.js для обработки загрузки CSV через интерфейс.

Скрипт автоматически оставляет только нужные поля, отфильтровывает доходы, внутренние переводы и операции без категории, формируя легкий JSON-файл, с которым дашборд загружается мгновенно.

1. Сохраните выгруженный файл как `data.csv` в корне проекта.
2. Запустите конвертацию:
   ```bash
   python convert.py
   ```
3. Скрипт создаст оптимизированный файл `data.json`, который можно напрямую загрузить на ваш статический хостинг вместе с остальными файлами.

## 🔐 Безопасность

> [!CAUTION]
> **Этот репозиторий не содержит механизмов аутентификации.** Демо-страница [mikhaildudin.ru/ztest/](https://mikhaildudin.ru/ztest/) намеренно открыта и содержит только анонимизированные тестовые данные — она не требует авторизации.
>
> **Перед публикацией приложения с реальными данными вы обязаны добавить защиту доступа.** Без этого любой человек, узнавший URL, сможет:
> - 👁️ **Прочитать** все ваши финансовые записи (содержащие точные суммы, контрагентов, даты)
> - 💾 **Перезаписать или навсегда уничтожить ваши данные** — эндпоинт импорта CSV (`api/import.php` / маршрут Node.js) не имеет встроенной аутентификации и молча заменит `data.json` любым загруженным файлом, что приведёт к **необратимой потере данных**.

### Настройка аутентификации по типу хостинга

**Apache / cPanel (виртуальный хостинг) — HTTP Basic Auth:**

Создайте `.htaccess` и `.htpasswd` непосредственно на сервере (не добавляйте их в Git — они уже исключены через `.gitignore`):

```apache
AuthType Basic
AuthName "ZenMoney Viewer — Доступ закрыт"
AuthUserFile /полный/путь/на/сервере/.htpasswd
Require valid-user
```

Сгенерируйте хэш пароля (запустите на сервере или локально с Apache utils):
```bash
htpasswd -c /полный/путь/на/сервере/.htpasswd ваш_логин
```

**Node.js — Basic Auth middleware:**
```bash
npm install express-basic-auth
```
```js
const basicAuth = require('express-basic-auth');
app.use(basicAuth({ users: { 'admin': 'ваш_надёжный_пароль' }, challenge: true }));
```

**Статический хостинг (GitHub Pages, Netlify, AWS S3 и т.п.):**
Такие платформы не могут самостоятельно защитить доступ серверными средствами. Используйте один из вариантов:
- **Cloudflare Access** (есть бесплатный тариф) — добавляет страницу входа перед любым публичным URL
- **Netlify Identity** — встроенный механизм защиты для Netlify
- Или просто **не размещайте реальные данные на статическом хостинге** — используйте `convert.py` локально, а данные загружайте только на защищённый сервер

> [!IMPORTANT]
> Никогда не публикуйте свой реальный `data.json`, файлы `*.csv` или файл паролей `.htpasswd` в открытых репозиториях GitHub. В репозиторий включён настроенный `.gitignore`, который автоматически исключает эти файлы.

**Apache — запрет прямого скачивания конфиденциальных файлов:**
```apache
<FilesMatch "^(data\.json|data\.csv|zen_history\.csv|convert\.py|\.htpasswd)">
    Require all denied
</FilesMatch>
```
Это запрещает скачивание конфиденциальных файлов напрямую по URL, даже если кто-то угадает путь.
